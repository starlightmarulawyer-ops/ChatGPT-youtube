# 충녕 유튜브

충녕 유튜브 영상의 기획, 제작, 편집 및 관리를 위한 Codex 프로젝트입니다.

## 저장 범위

이 저장소에는 Codex 로컬 프로젝트 **충녕 유튜브** 안에서 생성하거나 관리하는 작업 파일을 모읍니다.
개별 채팅 하나가 아니라 프로젝트 전체가 대상입니다.

- 영상 아이디어, 조사 자료, 기획안, 대본
- 촬영·편집 계획, 자막, 썸네일과 프로젝트에 포함된 미디어
- 업로드 제목·설명·태그, 일정과 운영 문서
- 제작·관리 코드, 도구, 프로젝트 설정

다른 프로젝트나 프로젝트 밖의 채팅 자료는 자동으로 가져오지 않습니다.

## 작업과 업로드

1. 이 프로젝트의 작업 파일은 이 저장소 폴더 안에 저장합니다.
2. 작업을 마치면 변경 내용을 확인하고 커밋한 뒤 이 저장소에 푸시합니다.
3. 인증정보, 비밀키, 로컬 환경 파일, 의존성 및 캐시는 Git에 포함하지 않습니다.
4. GitHub 파일 크기 제한을 넘는 영상 등은 Git LFS 등 적절한 저장 방법을 적용하고, 업로드하지 못한 항목은 보고합니다.

이 문서와 AGENTS.md는 Codex 작업 지침입니다. ChatGPT 대화 원문이 자동으로 파일화되거나 모든 기기가 실시간 동기화되는 설정은 아닙니다.
